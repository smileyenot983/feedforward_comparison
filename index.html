Metric definitions & aggregation
FG / BG disagreement
Relative cross-view depth disagreement in foreground / background, including occluded points. This is consistency between predictions.
CO3D FG depth error
Relative difference |prediction − reference| / reference on valid foreground CO3D depth pixels. These COLMAP reference depths can contain errors.
Aggregation
Scene-balanced median of per-scene medians. Reference error uses frame medians within each scene. Scenes without a valid score are omitted; FG / BG scene counts are shown for each row.
Runtime / memory
Saved inference runtime and peak allocated GPU memory. Grids and execution paths differ; these measurements are indicative. GGPT runtime includes Pi3X, matching, camera optimization and refinement.
Missing values
“—” means unavailable or not applicable. The sparse CO3D baseline has no self-comparison error or inference timing.

Methods & evaluation setup

This page presents an exploratory comparison on 20 selected CO3D scenes, using 10 views per scene. It is a saved experiment, not an official benchmark or an evaluation of the full dataset.

Camera inputs

Primary Pi3X, DA3, MapAnything and pairwise Pow3R runs received CO3D cameras. VGGT-Omega received RGB only. Its primary cloud reprojects predicted depths with CO3D cameras; its alternate cloud uses predicted cameras. These are two displays of the same inference run.

Pointcloud display

Clouds combine points from the selected views without surface fusion or smoothing. All methods share one scene display transform, scale and viewpoint. Foreground masks affect display only. Each method retains its saved geometry-validity mask.

Sampling & additional protocol details

Clouds were sampled at stride 3 and capped at 60,000 foreground and 20,000 background points per method. These display samples are separate from the evaluation pixels. Use the interactive viewer’s Overview control to inspect distant points.

RGB-only MapAnything and Pi3X predict their own cameras; CO3D cameras are used afterward for a single similarity alignment and evaluation. GGPT refines Pi3X with matching and camera optimization, retaining corrected XYZ. Its camera-conditioned, RGB-only and fast-matcher variants have separate retained-pixel intersections.

This public export preserves the original experiment’s pointclouds and scores. It does not substitute later 30-view preprocessing or filtering results.
